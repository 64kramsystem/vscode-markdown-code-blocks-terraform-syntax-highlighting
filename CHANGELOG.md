# Change Log

## 0.2.0

- Highlight Terraform blocks in the built-in Markdown Preview using the same bundled grammar as the editor.
- Target desktop VS Code; web editors are no longer supported.

## 0.1.0

- Bundle the HashiCorp Terraform grammar so highlighting works without another extension.
- Support `tf` and `terraform` fences, including uppercase names, tilde fences, lists, and blockquotes.
- Fix closing-fence handling and prevent highlighting inside unrelated code blocks.
- Isolate grammar and language identifiers from other extensions.

## Earlier releases

Required an independently installed language grammar.
